## About Dnsglobe

After changing a DNS record, we usually need to check whether the update has reached DNS servers worldwide. Opening a website like WhatsMyDNS every time can be extra work, especially when you’re already in the terminal.

dnsglobe is a global DNS propagation checker that you can use to query a domain, see propagation progress across different locations, and watch the results in a visualization.
